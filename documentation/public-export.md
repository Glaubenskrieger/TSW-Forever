# Public source export and private development boundary

The public `Glaubenskrieger/TSW-Forever` repository contains the owner-published source and its tag-triggered release workflow (`0.2.0` was the first Linux release; `0.3.0` adds the native Windows client and the combined Linux/Windows release set). Only the owner performs Git actions, tagging and publication there. The private `Glaubenskrieger/TSW-Forever-Dev` repository retains internal history, research, reports, tools and workflows. Public and private trees are intentionally different.

The public export was selected from a checked private source snapshot and audited with `scripts/check_public_source.py`. It contains the editable Rust/Slint sources, used assets, three lockfiles, Flatpak packaging, build scripts, user instructions and complete required licence materials. It excludes private Git history, research and agent files, reports, local configuration, credentials, Wine prefixes, game data, original Funcom files, Microsoft DLLs and the private branding image. The public README is the standalone installation and source-build guide.

For later owner-directed exports, select and review the exact intended source snapshot; never copy the private working directory wholesale. Run source, licence, secret and content checks against that snapshot, compare file inventories and hashes, and retain the audit evidence privately. GPL corresponding source and build information must not be omitted. A scan reduces risk but does not guarantee that every possible secret is absent.

Only the project owner transfers files to the public repository and performs Git operations, tagging and publication. Agents may prepare local files and test isolated copies only when asked. No automatic synchronization between private and public repositories is authorized. The public project, release and issue URLs are respectively `https://github.com/Glaubenskrieger/TSW-Forever`, `https://github.com/Glaubenskrieger/TSW-Forever/releases` and `https://github.com/Glaubenskrieger/TSW-Forever/issues`.
