Why TSW-Forever?

Some worlds never let you go.

The Secret World is one of them for me. Since 2012, its secrets, its stories and its unmistakable atmosphere have stayed with me.

TSW-Forever is my contribution to keeping this world alive on modern systems – without changing the original.

Not to reinvent it. But so that the original can remain what it is.

Keeping the original

The launcher sets up the game you own and starts it. TSW-Forever contains no game files and does not replace any original game content with files of its own.

Modern systems

It takes care of the technical side so that the original runs on current Linux, SteamOS and Windows 10/11 installations.

Not Secret World Legends

This project is about the original game of 2012. It has nothing to do with Secret World Legends and offers no servers of its own.

What it does

Installs the game

Guides you through setting up the original game: through the download of the official Funcom installer (checked against a fixed SHA-256 checksum), through an installer you already have, or through an existing installation. On Windows the game runs natively, on Linux through Wine/Proton.

Remembers your display settings

The game resolution you choose is kept between starts. On Linux, an adjustable frame-rate limit comes on top.

Six languages, four themes

The launcher window speaks English, German, French, Spanish, Brazilian Portuguese and Polish, and comes in four colour themes: Templars, Illuminati, Dragon and a neutral one.

Installation and updates

Windows

  1. Download the installer. The SHA-256 checksum is a digital fingerprint of the file: calculate it in PowerShell and compare it with the value on this page or in SHA256SUMS. It must match exactly.
Get-FileHash .\tsw-forever-*-windows-setup.exe -Algorithm SHA256
  1. Run the installer. Windows asks for administrator permission once; choose your language in the first dialog.
  2. Start TSW-Forever from the Start menu. At the first start choose how to get the game: the official installer download, an installer you already have, or an existing installation.

The installer is not signed with a certificate. Windows may therefore show a SmartScreen warning ("Windows protected your PC"). Run it only if you downloaded it from the project's official source (this page or the project's release page on GitHub) and the checksum matches; then choose "More info" and "Run anyway". Do not switch off any Windows protection for this. If Windows blocks the installer completely, for example with Smart App Control switched on, it cannot be run on that computer.

Linux and SteamOS (Flatpak)

TSW-Forever itself is a Linux application (Flatpak). The original Windows game runs on Linux through Wine/Proton; the launcher downloads the matching environment during setup, with your confirmation. Requirements: Flatpak on an x86-64 computer, a Vulkan-capable graphics driver with 32-bit support, and XWayland. Flathub only supplies the Flatpak runtimes here; TSW-Forever is not published there. On SteamOS, do this in Desktop Mode.

Install

Check the download first: the SHA-256 value must match the one shown above or in SHA256SUMS.

sha256sum tsw-forever-*.flatpak

Download the Flatpak bundle above and install it for your user, without sudo. This is also how you install on a fresh system: Flatpak fetches the runtimes it needs from Flathub.

flatpak install --user ./tsw-forever-*.flatpak

Start TSW-Forever from your application menu, or in the terminal:

flatpak run org.tswlauncher.Launcher

Updates

Every time you start it, TSW-Forever checks whether a newer version has been published. If there is one, the launcher shows a notice with a button that takes you to the matching download on this page. That is all it does: it never downloads or installs anything by itself. You decide whether and when you update.

Updating is always done by hand: you download the new file yourself and install it yourself. Your settings and your game folder are kept.

Windows

Run the new installer over the old version. You do not need to uninstall anything first.

  1. In the launcher notice, click "Open download page". Your browser opens this page at the Windows download. (Without the notice, simply go to Downloads at the top of this page.)
  2. Click "Download Windows installer" and wait until the file is saved, usually in your Downloads folder. If you like, check the SHA-256 value as described under Installation above.
  3. Double-click the downloaded file and confirm the Windows permission prompt. The installer recognises the existing installation and offers to update it; keep the suggested folder. If TSW-Forever is still open, the installer asks you to close it first.
  4. Start TSW-Forever from the Start menu. Your settings and your game folder are still there.

Linux and SteamOS

Install the new bundle the same way as the first one, over the old version. You do not need to uninstall anything first.

  1. In the launcher notice, click "Open download page". Your browser opens this page at the Linux download. (Without the notice, simply go to Downloads at the top of this page.)
  2. Click "Download Flatpak" and wait until the file is saved, usually in your Downloads folder. If you like, check the SHA-256 value as described under Installation above.
  3. Close TSW-Forever, open a terminal in the folder with the downloaded file and run the command below. Replace the file name with the one you downloaded; it contains the version number.
flatpak install --user ./tsw-forever-X.Y.Z.flatpak
  1. Start TSW-Forever from your application menu. Your settings and your game folder are still there.

Install only a newer bundle than the one you have. Flatpak does not warn you if you install an older one: the installation then simply goes back to that older version.

Questions about updates

How do I know that a new version exists?

When the launcher starts, it quickly asks GitHub which version was published last (it only reads the version number). If that version is newer than yours, a notice appears in the launcher window. You can also look at the Downloads section of this page at any time.

Does the launcher download or install anything by itself?

No. It only shows the notice. The button opens this web page in your browser; nothing is downloaded and nothing is installed until you do it yourself.

Do I have to update right away?

No. You can keep playing with your current version for as long as you like. The notice appears again at the next start, until you have installed the new version.

Will I lose my settings or my game?

No. The update replaces only the launcher. Your settings and the game folder with the original The Secret World stay where they are.

I see no notice, although a new version exists. Why?

The launcher needs an internet connection at start, and only the official stable version shows the notice. In that case, just look at the Downloads section of this page: the buttons always offer the newest published version.

About TSW-Forever

TSW-Forever is a free, independent launcher for the original The Secret World (2012), developed as a community project. The source code of released versions is available on GitHub under GPL-3.0-or-later. The aim is simple: keep the original game easy to install and to start, on today's systems.

Open source

The source code of released versions is available on GitHub under GPL-3.0-or-later. The game, Wine/Proton and Microsoft components are not part of the project and keep their own terms.

Our approach

Careful before fast: the launcher downloads and installs game components only after you have started the setup yourself. What it downloads on its own is checked against fixed checksums. We only promise what can be shown to work.
